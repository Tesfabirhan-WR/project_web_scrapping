# Project_web_scrapping

As a Data Engineer, undertaking the collection of web-based data using appropriate acquisition and extraction techniques, ensuring data quality through systematic validation, cleaning, and preparation processes, is crucial task to understand and execute. From the data collected, development, assessessement, and optimisation are followed to estalish need based data.  From the data collected, all methodological decisions are substantiated through rigorous quantitative evaluation and performance measurements can be implemented.

In this project,  data scrapping is applied using beautiful soap from a web site specifically developed for teaching purpose. More than 1000 books displayed in 50 pages are scrapped.
